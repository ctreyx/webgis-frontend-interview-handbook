# 每个步骤深度解析

## ① Parse 阶段

```text
┌────────────────────────────────────────────────────────────┐
│ HTML Parser → DOM Tree │
│ │
│ 关键细节： │
│ • 遇到 <script> 标签默认阻塞 HTML 解析 │
│ （脚本可能操作 DOM，必须等它执行完） │
│ • async: 并行下载，下载完立刻执行（仍阻塞解析） │
│ • defer: 并行下载，DOM 构建完再执行（不阻塞） │
│ • 预扫描器（Preload Scanner）并行扫描后续资源并预加载 │
│ │
│ CSS Parser → CSSOM Tree │
│ • CSS 构建期间阻塞渲染（不阻塞 DOM 解析） │
│ • CSSOM 必须完整构建完才能构建 Render Tree │
│ • 这就是为什么 CSS 要放 <head>！ │
└────────────────────────────────────────────────────────────┘
```

## ② Render Tree 构建

```text
┌────────────────────────────────────────────────────────────┐
│ DOM + CSSOM → Render Tree │
│ │
│ • display:none 的节点不进入 Render Tree │
│ • visibility:hidden 进入（占位但不可见） │
│ • 伪元素 ::before/::after 进入（虽不在 DOM） │
└────────────────────────────────────────────────────────────┘
```

## ③ Layout（布局/回流）

```text
┌────────────────────────────────────────────────────────────┐
│ 计算每个 Render Tree 节点的精确几何信息 │
│ │
│ • 输入：Render Tree + 视口尺寸 │
│ • 输出：每个元素的 x/y/width/height │
│ • 流式布局：父节点影响子节点，某节点改变可能引发全局回流 │
│ • 性能最重！O(n) 甚至 O(n²) 复杂度 │
└────────────────────────────────────────────────────────────┘
```

## ④ Paint（绘制）

```text
┌────────────────────────────────────────────────────────────┐
│ 生成绘制指令列表（Display List / Paint Record） │
│ │
│ ★ 注意：这里不是真正画像素！ │
│ 是生成类似： │
│ drawRect(0, 0, 100, 100, '#fff') │
│ drawText('Hello', 10, 20, 'red', '14px Arial') │
│ 这样的指令序列 │
│ │
│ 实际像素填充在光栅化步骤完成 │
└────────────────────────────────────────────────────────────┘
```

## ⑤ Layer Compositing（图层合成）

```text
┌────────────────────────────────────────────────────────────┐
│ 哪些情况会创建独立合成层？ │
│ │
│ • transform: translateZ(0) / will-change: transform │
│ • opacity 动画 │
│ • <video> <canvas> <iframe> │
│ • position:fixed │
│ • CSS filter │
│ │
│ 独立层的优势： │
│ 该层变化时，其他层不需要重新 Paint │
│ 直接在 Compositor 线程（独立线程！）合成 │
│ │
│ ★ transform/opacity 动画不触发 Layout 和 Paint │
│ 直接走 Compositor 线程 → 60fps 丝滑！ │
└────────────────────────────────────────────────────────────┘
```

## ⑥ GPU 光栅化 + 显示

```text
┌────────────────────────────────────────────────────────────┐
│ 各图层独立光栅化（将绘制指令转为位图） │
│ → GPU 合并各图层位图 │
│ → 送入帧缓冲区 │
│ → 显示器扫描显示 │
└────────────────────────────────────────────────────────────┘
```
