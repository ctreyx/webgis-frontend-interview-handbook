# 1. Suspense 在 CSR（非SSR）项目里能做什么？和 lazy 配合的原理是什么？

## lazy + Suspense 工作原理

1. lazy 返回一个特殊的组件

```js
const WeatherMap = lazy(() => import("./WeatherMap"));
```

- import() 返回 Promise
- lazy 内部用 throw Promise 来通知 Suspense

2. 核心原理：throw Promise！

- React 渲染 WeatherMap 时
- 发现模块还没加载 → 抛出一个 Promise
- throw promise ← 这是关键！

3. Suspense 捕获这个 Promise

- 显示 fallback（Loading组件）
- 等 Promise resolve（模块加载完成）
- 重新渲染子组件

## 简化原理

```js
function lazy(importFn) {
  let status = "pending";
  let result;
  const promise = importFn().then((module) => {
    status = "success";
    result = module.default;
  });

  return function LazyComponent(props) {
    if (status === "pending") throw promise; // ⬅️ 抛出 Promise！
    if (status === "success") return <result {...props} />;
  };
}
```

## 核心结论

核心：throw Promise 是 Suspense 的底层机制。
不只是 lazy，任何组件 throw 一个 Promise，都会被 Suspense 捕获。
