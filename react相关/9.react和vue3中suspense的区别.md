# react和vue3中suspense的区别

## React Suspense

- 捕获子组件 throw 的 Promise
- 用于：lazy加载、数据获取（配合支持Suspense的库）

## Vue3 Suspense

- 专门为异步 setup 设计的
- 当子组件的 setup 是 async 时自动触发

## Vue3 特有：async setup

```js
const AsyncWeatherMap = {
  async setup() {
    // setup 可以是 async！React 不支持这个
    const data = await fetch("/api/weather").then((r) => r.json());
    return { data };
  },
};
```

## 父组件用 Suspense 包裹

```vue
<template>
  <Suspense>
    <template #default>
      <AsyncWeatherMap />
      <!-- async setup 触发 Suspense -->
    </template>
    <template #fallback>
      <Loading />
    </template>
  </Suspense>
</template>
```

## 核心区别对比

- React Suspense：throw Promise 机制，通用
- Vue3 Suspense：专为 async setup 设计，更简洁
