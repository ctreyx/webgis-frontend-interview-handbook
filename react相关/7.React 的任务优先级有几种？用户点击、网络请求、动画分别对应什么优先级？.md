# React 的任务优先级有几种？用户点击、网络请求、动画分别对应什么优先级？

答案：一共5种。

```js
// packages/scheduler/src/SchedulerPriorities.js

export const NoPriority = 0; // 无优先级
export const ImmediatePriority = 1; // 立刻执行，同步
export const UserBlockingPriority = 2; // 用户阻塞级
export const NormalPriority = 3; // 正常
export const LowPriority = 4; // 低
export const IdlePriority = 5; // 空闲时执行
```

## 优先级 / 超时时间 / 对应 Lane

| 优先级               | 超时时间       | 对应 Lane                    | 说明                               |
| -------------------- | -------------- | ---------------------------- | ---------------------------------- |
| ImmediatePriority    | -1ms（已过期） | SyncLane                     | 立刻同步执行，不进队列             |
| UserBlockingPriority | 250ms          | InputContinuousLane          | 250ms 内必须处理，否则用户感知卡顿 |
| NormalPriority       | 5000ms         | DefaultLane / TransitionLane | 5秒过期                            |
| LowPriority          | 10000ms        | TransitionLane               | 10秒过期                           |
| IdlePriority         | 永不过期       | IdleLane / OffscreenLane     | 浏览器真正空闲才执行               |

## 优先级 → 调度时序

高 ←──────────────────────────────────── 低

Immediate UserBlocking Normal Low Idle
[立刻] [250ms] [5s] [10s] [∞]

## 任务队列（minHeap，按 expirationTime 排序）

1. 新任务进来 → 计算 expirationTime = currentTime + timeout
2. 插入小顶堆
3. 每次取堆顶（最紧急的）执行
4. 执行超时 → 让出 → 下一帧继续取堆顶

# // Scheduler 5种优先级：

// 1. ImmediatePriority（立即执行）
// → 同步任务，不可中断
// → 对应：React.flushSync

// 2. UserBlockingPriority（用户阻塞）
// → 用户交互：点击、输入、滚动
// → 250ms 内必须响应，否则用户感觉卡顿
// → 对应：onClick、onChange

// 3. NormalPriority（普通）
// → 网络请求回调、普通 setState
// → 5000ms 过期
// → 对应：fetch().then(setData)

// 4. LowPriority（低优先级）
// → 数据预加载、非关键更新
// → 10000ms 过期

// 5. IdlePriority（空闲）
// → 浏览器空闲时才执行
// → 永不过期
// → 对应：startTransition 标记的更新

// 地图项目对应：
// 用户点击站点 → UserBlockingPriority ⚡
// WebSocket推送数据 → NormalPriority
// 风场粒子动画更新 → LowPriority
// 预加载下一时段数据 → IdlePriority
