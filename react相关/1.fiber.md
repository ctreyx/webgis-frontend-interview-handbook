# Fiber 节点上都有哪些关键属性

属性 作用
type 节点类型（div/组件函数等）
return 父 Fiber
child 第一个子 Fiber
sibling 下一个兄弟 Fiber
memoizedState hooks 链表（重要）
pendingProps / memoizedProps 新旧 props
flags 副作用标记（Placement/Update/Delete）
lanes 优先级
alternate 指向对应的另一棵树的 Fiber

# 什么是双缓冲树（double buffering）？current 树和 workInProgress 树是如何切换的？

首次渲染:
current树 = null
workInProgress树 构建完成 → commit → 变成 current树

更新时:
以 current树 为基础，克隆创建 workInProgress树
↓
workInProgress 计算完成（render阶段）
↓
commit 阶段将 workInProgress 变成新的 current
↓
两棵树通过 fiber.alternate 互相指向对方
好处：DOM更新是原子性的，用户永远看到完整的界面，不会看到中间状态
