


React.lazy 的懒加载本质是依赖了 ES 的动态 import() 

// 你传入的是一个函数，不是直接执行
const WeatherMap = lazy(() => import('./WeatherMap'))
//                        ↑
//                   这是函数，不是 import('./WeatherMap')
//                   lazy 只是把它存起来，不执行


// 第一次渲染 WeatherMap 时：
// 1. 执行 () => import('./WeatherMap')
// 2. 浏览器才开始下载这个 chunk 文件
// 3. 下载完成前 → throw Promise → Suspense 显示 fallback
// 4. 下载完成后 → 重新渲染 → 显示真正的组件

// 第二次渲染同一个 lazy 组件：
// → status 已经是 resolved
// → 直接返回缓存的组件
// → 不会再次发网络请求


// ❌ 没有 lazy：打包时所有组件打进一个 bundle
// 用户进入首页 → 下载包含所有页面的 JS → 很慢

// ✅ 用了 lazy：Vite/Webpack 自动代码分割
// WeatherMap → 单独打包成 chunk-xxx.js
// 用户进入首页 → 只下载首页的 JS → 快
// 用户进入地图页 → 才下载 WeatherMap 的 chunk → 按需加载
