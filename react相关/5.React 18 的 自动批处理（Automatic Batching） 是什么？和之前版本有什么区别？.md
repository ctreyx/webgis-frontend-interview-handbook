# React 18 的 自动批处理（Automatic Batching） 是什么？和之前版本有什么区别？

React 17：只有 React 事件处理函数内部才自动批处理
老版本只有合成事件才会批处理，比如 settimeout promise 原生事件不会进行批处理

React 18 自动批处理：全场景覆盖，settimeout promise 原生事件全部覆盖

性能收益举例（地图大屏场景）：

WebSocket 推送天气数据：
setTemperatureData(data); // 更新温度图层
setWindData(data); // 更新风场图层
setRainfallData(data); // 更新降雨图层
setLastUpdateTime(now); // 更新时间戳

React 17: 4 次独立渲染 → 4 次 Cesium 重绘 → 帧率暴跌
React 18: 自动批处理 → 1 次渲染 → 平稳 60fps
