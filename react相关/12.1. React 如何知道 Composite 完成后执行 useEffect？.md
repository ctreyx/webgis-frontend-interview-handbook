# 1. React 如何知道 Composite 完成后执行 useEffect？


宏任务1：React commit阶段（layout结束）
    ↓
    React 用 MessageChannel 发一个宏任务
    ↓
浏览器利用宏任务间隙：
    Style → Layout → Paint → Composite
    ↓
宏任务2：useEffect 执行


关键在于：浏览器的渲染（Paint/Composite）发生在两个宏任务之间的间隙

MessageChannel 发出的是宏任务，所以浏览器在执行下一个宏任务之前，会先完成渲染。

React 利用的是这个时序规律，而不是监听了什么"渲染完成"事件。
