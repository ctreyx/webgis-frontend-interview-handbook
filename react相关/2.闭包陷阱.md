# 闭包陷阱本质：

# /React 每次渲染都是一个独立的函数调用 每次渲染都有自己的 count 快照，注意用词，是快照

```js
// 第一次渲染：count = 0
function WeatherTimer() {
  const count = 0; // 这次渲染的快照
  useEffect(() => {
    // 这个函数闭包捕获了 count = 0
    // 无论之后 count 怎么变，这里永远是 0
    setInterval(() => console.log(count), 1000);
  }, []);
}

// 第二次渲染：count = 1
function WeatherTimer() {
  const count = 1; // 新的快照
  // 但 useEffect 没有重新执行（依赖是空数组）
  // 定时器还是用的上一次闭包里的 count = 0
}
```

useEffect(() => {
  setInterval(() => {
    setCount(prev => prev + 1); // prev 永远是最新的
  }, 1000);
