# Block Tree + PatchFlag

## 1. 先说为什么需要它

Vue2 / 传统 vdom diff 的问题：

```html
<div>
  <p>静态文本</p>
  <p>静态文本</p>
  <p>静态文本</p>
  <p>{{ msg }}</p>
  <!-- 只有这个会变 -->
  <p>静态文本</p>
</div>
```

每次 msg 变化 → 重新渲染整棵树
diff 时：对比所有 5 个 <p>，包括 4 个根本不会变的
→ O(n) 对比，大量无效工作

理想状态：我知道只有第 4 个 <p> 会变，只对比它就够了
→ 这就是 Block Tree + PatchFlag 要做的事

## 2. Block Tree —— 收集“哪些节点会变”

```js
// 每个 Block 节点都有一个 dynamicChildren 数组
// 编译时把所有动态子孙节点收集进来
const block = {
  type: 'div',
  props: {},
  children: [...], // 完整子树（渲染用）
  dynamicChildren: [ // ★ 只有动态节点！（diff 用）
    { type: 'p', children: msg, patchFlag: PatchFlags.TEXT }
  ]
}
```

Block Tree 的核心思想是**“扁平化”**。编译器将模板切割成一个个独立的 Block（块）。每个 Block 是一个最小的响应式更新单元，它内部聚合了所有具有相同响应式依赖的动态节点。

结构变革：Block 不再维护完整的树形层级，而是维护一个名为 dynamicChildren 的扁平数组。
更新策略：当状态变更时，Vue 不再遍历整棵树，而是直接定位到对应的 Block，仅对其 dynamicChildren 数组中的节点进行比对。

模板：

```html
<div>
  <p>静态</p>
  <p>静态</p>
  <p>{{ msg }}</p>
  <!-- 动态 -->
  <p>静态</p>
</div>
```

编译后（简化）：

```js
function render() {
  return (
    openBlock(),
    createElementBlock("div", null, [
      createElementVNode("p", null, "静态"), // 无 patchFlag → 不进 dynamicChildren
      createElementVNode("p", null, "静态"), // 同上
      createElementVNode("p", null, msg, 1), // TEXT flag → 进 dynamicChildren ★
      createElementVNode("p", null, "静态"), // 同上
    ])
  );
}
```

diff 时：

- 不 diff children（4个 p），直接 diff dynamicChildren（只有 1 个 p）
- O(1) 直接命中动态节点！
