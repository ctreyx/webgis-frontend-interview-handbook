# Vue3 的 defineProps 和 defineEmits 为什么不需要 import？他们是怎么工作的？

## 核心原因

- defineProps 和 defineEmits 是编译器宏（Compiler Macro）
- 不是运行时函数，所以不需要 import！

## 对比示例

```js
// ❌ 普通函数需要 import：
import { ref, computed } from "vue"; // 运行时函数，需要 import

// ✅ 编译器宏不需要 import：
const props = defineProps(["name"]); // 编译时处理，不是运行时
const emit = defineEmits(["change"]); // 同上
```

## 编译过程

编译前：

```vue
<script setup>
const props = defineProps({ name: String });
const emit = defineEmits(["update"]);
</script>
```

编译后：

```js
export default {
  props: {
    // ⬅️ defineProps 变成 options 的 props
    name: String,
  },
  emits: ["update"], // ⬅️ defineEmits 变成 options 的 emits

  setup(props, { emit }) {
    // ⬅️ 自动注入 props 和 emit
    // 可以直接用 props 和 emit
  },
};
```

## 其他编译器宏（同样不需要 import）

- defineExpose() → 控制对外暴露
- defineOptions() → 设置组件选项
- withDefaults() → 给 defineProps 设置默认值
