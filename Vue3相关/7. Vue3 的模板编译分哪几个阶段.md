# Vue3 的模板编译分哪几个阶段？

## 编译三阶段

- template 字符串 → AST
- AST → Transform
- Transform 结果 → render 函数

## 下面模板编译后的 render 函数大概长什么样？

### 第一阶段：Parse（解析）

template 字符串 → AST（抽象语法树）

```js
<template>
  <div class="weather">
    <span>{{ station.name }}</span>
    <span :class="{ active: isActive }">{{ temperature }}°C</span>
    <button @click="handleClick">刷新</button>
  </div>
</template>
```

解析成 AST：

```js
const ast = {
  type: "Element",
  tag: "div",
  props: [{ name: "class", value: "weather" }],
  children: [
    {
      type: "Element",
      tag: "span",
      children: [
        {
          type: "Interpolation", // 插值表达式
          content: "name",
        },
      ],
    },
  ],
};
```

### 第二阶段：Transform（转换）

- 遍历 AST，打上 PatchFlag 标记
- 标记静态节点、动态节点
- 收集动态节点到 Block

### 第三阶段：Generate（代码生成）

AST → render 函数字符串

编译后的 render 函数（示意）：

```js
import { createElementVNode as _c, normalizeClass, toHandlerKey } from "vue";

// 静态提升（hoistStatic）
const _hoisted_1 = { class: "weather" }; // 静态属性提升到外部

function render(ctx) {
  return _c("div", _hoisted_1, [
    // span1：只有动态 text → PatchFlag = 1
    _c("span", null, ctx.station.name, 1 /* TEXT */),

    // span2：动态class + 动态text → PatchFlag = 3
    _c(
      "span",
      {
        class: normalizeClass({ active: ctx.isActive }),
      },
      ctx.temperature + "°C",
      3 /* TEXT + CLASS */,
    ),

    // button：只有静态事件 → 不需要 PatchFlag
    _c("button", { onClick: ctx.handleClick }, "刷新"),
  ]);
}
```
