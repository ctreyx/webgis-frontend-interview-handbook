# Vue3 nextTick

## 核心结论

nextTick 本质是 Promise.then，Vue 的响应式更新任务和 nextTick 的回调都在微任务队列里。更新任务先进队列，回调后进队列，微任务按顺序执行，所以回调一定在 DOM 更新之后执行。

## 执行链路

```text
数据变化（ref.value = 'new'）
↓
触发 setter → queueJob(componentUpdateFn)
↓
queueFlush()
↓
currentFlushPromise = resolvedPromise.then(flushJobs)
↑ DOM 更新任务 进入微任务队列，位置 #1

此时调用 nextTick(fn)：
↓
return currentFlushPromise.then(fn)
↑ fn 挂在 currentFlushPromise 后面，位置 #2
```

## 微任务队列执行顺序

1. #1 flushJobs() → 执行所有组件更新 → DOM 更新完毕
2. #2 fn() → nextTick 回调 → 此时 DOM 已经是最新的 ✅

# 组件实例更新

```js
const effect = new ReactiveEffect(componentUpdateFn, () =>
  queueJob(instance.update),
);

let queue = [];
let isFlugsing = false;
const resolvePromise = Promise.resolve();

export function queueJob(job) {
  if (!queue.includes(job)) {
    queue.push(job);
  }

  if (!isFlugsing) {
    isFlugsing = true;
    // -->用异步，是为了等待age++完成再渲染
    resolvePromise.then(() => {
      isFlugsing = false;
      let copy = queue.slice(0); //避免处理时又更新值，开辟新地址
      queue.length = 0; //-->拷贝完后马上清空，避免执行时放入任务，被清空
      for (let i = 0; i < copy.length; i++) {
        let job = copy[i];
        job();
      }

      copy.length = 0; //-->清空回收
    });
  }
}
```
