# 事件通讯

核心难点与突破：事件通讯 低代码场景下组件高度解耦，地图、底图切换按钮、图例、工具栏之间需要频繁通讯。最初用普通 EventBus（mitt），但很快出现内存泄漏：底图切换按钮销毁后，地图侧仍在持续 emit，监听器无法自动解绑，长时间运行的大屏内存持续上涨。

我基于对 Vue3 响应式原理的深入理解，自研了一套轻量事件中心：

数据结构完全对齐 Vue3 的 targetMap → depsMap → dep
使用 WeakMap 作为 targetMap，避免组件实例无法被垃圾回收
在 setup 中绑定事件时，vue3底层源码是通过 getCurrentInstance() 获取当前实例，所以基于这点，我写绑定中会把解绑逻辑注册到 onUnmounted 中
组件销毁时自动 off，开发者几乎不用手动管理，从根源上解决忘记解绑的问题
同时为低代码动态创建的组件提供了 uid 标识 
这套事件总线后来成为渲染引擎的通讯基础，既解决了泄漏，又降低了业务开发的心智负担。
