**针对 GitHub Copilot + 前端管理页面的完整解决方案**

你主要用 **Copilot**，我按这个工具给你最精准、可直接落地的方案。

### 一、如何让 AI 每次询问都自动遵守规范、不会失忆（核心）

Copilot 的持久记忆主要靠这几个机制（按效果排序）：

1. **最有效（强烈推荐）**：项目根目录创建  
   `.github/copilot-instructions.md`  
   → 这个文件会被 **自动加载到每一次 Chat 和代码生成** 中，团队共享，防失忆效果最好。

2. **辅助加强**：
   - 在 VS Code 设置里加 `github.copilot.chat.codeGeneration.instructions`
   - 每次新开 Chat 时手动 `@workspace` 或拖入规范文件
   - 把高频 Skills 写成独立 `.md` 文件，需要时 `@文件名` 引用
   - 在关键文件顶部加 `/* copilot-instructions: ... */` 注释

**操作步骤（5分钟搞定防失忆）**：
1. 在项目根目录新建文件夹 `.github`
2. 新建文件 `copilot-instructions.md`，把下面我给你的内容粘贴进去
3. 提交到 Git（团队所有人就自动生效）
4. 以后直接在 Copilot Chat 里说话即可，它会自动遵守

### 二、精准提示词（直接复制到 `.github/copilot-instructions.md`）

```markdown
# 前端管理后台开发规范（Vue3 + TypeScript + Element Plus）

你是本团队的高级前端工程师，专门负责中后台管理系统开发。必须严格遵守以下所有规范，生成的代码必须可直接运行、可维护、符合团队标准。

## 技术栈（强制）
- Vue 3 + `<script setup lang="ts">` + Composition API
- TypeScript（严格模式，禁止 any）
- Element Plus（优先使用官方组件）
- Pinia（状态管理）
- Vue Router
- Axios + 统一 request 封装（@/utils/request）
- 使用团队已有的 hooks 和工具函数（优先复用 @/hooks、@/components、@/utils）

## 管理页面标准结构（必须遵守）
每个列表管理页面必须包含：
1. 搜索/筛选区域（el-form + el-form-item）
2. 操作按钮区（新增、导出、批量删除等）
3. el-table 表格（带 loading、空状态、多选）
4. 分页（el-pagination）
5. 新增/编辑弹窗或抽屉（el-dialog / el-drawer）
6. 完整的 TypeScript 接口定义

## 代码强制规范
- 所有变量、函数、组件名使用有意义的中英文结合命名
- 必须处理 loading、error、空数据三种状态
- 表单必须有完整规则校验（rules）
- 接口调用必须使用 try/catch，并给用户友好提示（ElMessage）
- 禁止魔法数字和硬编码，抽成常量
- 组件超过 300 行必须拆分
- 优先使用 unplugin-auto-import 已自动导入的 API
- 样式使用 scoped + less/scss，或 UnoCSS（根据项目）
- 权限指令使用 v-auth 或项目现有权限方案

## 输出要求（每次必须）
1. 先简要说明实现思路和文件结构
2. 再给出完整可复制的代码
3. 明确告知需要新建/修改哪些文件
4. 代码必须带清晰中文注释
5. 最后给出使用说明和注意事项

## 禁止事项
- 禁止使用 Options API
- 禁止 any 类型
- 禁止直接修改 props
- 禁止在模板里写复杂逻辑
- 禁止忽略错误处理
```

### 三、前端管理页面 Skills 脚本（可直接用）

把下面内容保存为项目里的文件，例如：  
`docs/skills/admin-page.md` 或 `.github/skills/create-admin-page.md`

**以后使用方法**（防失忆关键）：
在 Copilot Chat 里输入：
```
@docs/skills/admin-page.md  请根据这个 skill 帮我创建一个【用户管理】页面
字段包括：用户名、手机号、角色、状态、创建时间
需要搜索、新增、编辑、删除、批量删除、分页
```

**完整 Skill 内容（复制使用）：**

```markdown
# Skill：创建标准管理页面（CRUD）

## 角色
你是资深 Vue3 中后台前端专家，严格按团队规范生成代码。

## 输入参数（用户会提供）
- 页面名称（中文 + 英文）
- 字段列表（字段名、类型、是否搜索、是否表格显示、是否表单、校验规则）
- 是否需要：新增、编辑、删除、批量删除、导出、详情
- 特殊需求（权限、自定义列等）

## 生成规则（必须 100% 遵守）
1. 使用 Vue3 + script setup + TypeScript
2. 完整文件结构建议：
   - views/xxx/index.vue          （主页面）
   - views/xxx/components/XxxForm.vue  （表单组件）
   - api/xxx.ts                   （接口）
   - types/xxx.ts                 （类型定义）

3. 主页面必须包含：
   - 搜索表单（支持重置、折叠）
   - 工具栏按钮
   - el-table（对齐、宽度、插槽、操作列固定右侧）
   - 分页
   - loading 状态
   - 空数据展示

4. 表单弹窗/抽屉规范：
   - 新增和编辑共用一个组件
   - 使用 el-form + rules 完整校验
   - 提交时按钮 loading
   - 成功后刷新列表并关闭

5. 接口层：
   - 使用项目统一的 request
   - 定义清晰的 PageResult、ListParams 类型
   - 包含 getList、getDetail、create、update、delete、batchDelete

6. 代码质量：
   - 全部 TypeScript 类型
   - 中文注释关键逻辑
   - 使用 useTable 或项目已有 hooks（如果有）
   - 错误统一 ElMessage 处理
   - 支持键盘回车搜索

## 输出格式
1. 实现思路（3-5 条）
2. 需要创建的文件列表
3. 完整代码（按文件分开，可直接复制）
4. 路由配置示例
5. 使用注意事项
```

### 四、推荐日常使用姿势（效率最高）

1. **新建页面时**：
   ```
   @.github/copilot-instructions.md @docs/skills/admin-page.md
   创建「景区管理」页面，字段：景区名称、地址、开放时间、状态、封面图、排序
   需要搜索、新增、编辑、删除、上架/下架
   ```

2. **修改已有页面时**：
   ```
   请严格遵守 .github/copilot-instructions.md 的规范，
   帮我给当前用户管理页面增加「重置密码」功能和批量导出
   ```

3. **防止失忆技巧**：
   - 新开 Chat 第一句先写：`请先阅读并严格遵守 .github/copilot-instructions.md`
   - 或者直接把文件拖进 Chat 窗口
