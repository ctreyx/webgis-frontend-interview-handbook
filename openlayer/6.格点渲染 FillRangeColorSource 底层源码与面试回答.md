
# 格点渲染 FillRangeColorSource 底层源码与面试回答

> 来源：绍兴气象项目 `wind-rain/small-map`，核心封装在本地包 `spd-ol-ext` 里。

---

## 一、核心结论

格点色斑图用的是 **ImageCanvas 方案**——`FillRangeColorSource` 继承自 `ol/source/ImageCanvas`，自己接管 Canvas 2D 渲染，不存在逐 Feature 的对象开销。

**依赖的三个关键库：**

```js
// packages/ol-ext/dist/spd-ol-ext.esm-bundler.prod.js 第 12 行
import { GPU } from "gpu.js";                                        // GPU 并行计算
import { Contour, smoothLines, isolines, isobands } from "wcontour-js"; // 等值线/等值面插值算法
import D from "ol/source/ImageCanvas";                               // ImageCanvas 方案
import { WindLayer } from "ol-wind";                                 // 风场粒子动画
```

- `wcontour-js`：气象领域经典等值线算法（中国气象局 WContour 的 JS 移植），负责把离散格点插值成等值面/等值线
- `gpu.js`：把插值这种大量重复计算丢给 GPU 并行
- `ImageCanvasSource`：OpenLayers 的"渲染权交给你"图层方案

## 二、数据层：`DatasetGrid`（格点数据集）

后端返回的是规则网格数据：一维数组 `dvalues` + 行列数 + 经纬度边界。项目把它封装成 `DatasetGrid` 类：

```js
// 源码还原（dist 里 DatasetGrid 的真实实现）
class DatasetGrid {
  constructor(left, top, right, bottom, rows, cols, dimensions) {
    this.left = left      // 格点范围左边界（经度）
    this.top = top        // 上边界（纬度）
    this.right = right    // 右边界
    this.bottom = bottom  // 下边界
    this.rows = rows      // 行数
    this.cols = cols      // 列数
    this.width = this.right - this.left
    this.height = this.top - this.bottom
    // 关键：假设是等间距规则网格
    this.deltaX = this.width / this.cols    // 经向格点间距
    this.deltaY = this.height / this.rows   // 纬向格点间距
    this.dimensions = dimensions            // 1=标量(气温/降水) 2=风矢量(U+V)
  }

  // 行优先索引：第 dim 维、第 x 列、第 y 行 → 一维数组下标
  getIndex(dim, x, y) {
    return (y * this.cols + x) * this.dimensions + dim
  }

  // 经纬度 → 行列号（反过来 gridToXY 同理）
  xyToGrid(x, y) {
    if (x < this.left || x > this.right || y < this.bottom || y > this.top) return null
    return {
      x: Math.floor((x - this.left) / this.deltaX),
      y: this.rows - 1 - Math.floor((y - this.bottom) / this.deltaY)  // 注意 Y 轴翻转
    }
  }

  // 计算极值（跳过 noDataValue）
  calcExtreme() { /* 遍历 grid，跳过无效值，求 dMin/dMax */ }
}
```

**业务层构造（useMode.ts）：**

```js
// 后端数据 → DatasetGrid

  gridData.left, gridData.top, gridData.right, gridData.bottom,
  Number(gridData.rows), Number(gridData.cols), 1
)
datasetGrid.noDataValue = gridData.noDataValue ?? -99999
datasetGrid.grid = grid          // 一维数组，按行优先填值
datasetGrid.dMin = dMin
datasetGrid.dMax = dMax
```

## 三、渲染层：`FillRangeColorSource extends ImageCanvasSource`

这是标准的 **ImageCanvas 方案**，OpenLayers 视图每次变化（pan/zoom）都会回调你重写的 `canvasFunction`：

```js
// 类型声明（spd-ol-ext.d.ts）
declare class FillRangeColorSource extends ImageCanvasSource {
  _segements: ColorValueSegment[]   // 颜色分段
  _datasetGrid: DatasetGrid         // 格点数据
  _canvasContext: CanvasRenderingContext2D  // Canvas 2D 上下文
  _imgData: ImageData               // 像素数据（逐像素写 RGBA）
  _colorValues: number[]            // 颜色查找表 LUT
  _alphaValues: number[]            // 透明度查找表
  _isSmooth: boolean                // 是否平滑插值
  _isGradient: boolean              // 平滑时颜色是否渐变
  _isShowLabel: boolean             // 是否显示等值线标签
  _labelDigits: number              // 标签小数位
  _alpha: number                    // 整体透明度

  // 核心方法
  canvasFunction(extent, resolution, pixelRatio, size, projection): HTMLCanvasElement
  convertValueToColor(value): { r, g, b, a }   // 值 → 颜色（核心！）
  updateGrid(bounds, resolution): void          // 视图变化更新网格
  drawHeatPoints(extent): void                 // 逐格点填色
  drawLabel(): void                            // 绘制等值线标签
  drawGridLine(bounds): void                   // 绘制网格线
  drawWind(): void                             // 绘制风场
}
```

**业务层使用（useLayer.ts / useMode.ts）：**

```js
// ① 创建图层
new ImageLayer({
  source: new OE.Source.FillRangeColorSource({
    labelDigits: 1,
    isShowLabel: false,
    alpha: 150,
    isShowGridline: false,
    isSmooth: true,     // 平滑插值
    isGradient: true,   // 颜色渐变
    style: { fontFamily: 'Arial', fontSize: '30px', fill: false, stroke: false }
  }),
  properties: { name: '雷达图层', id: 'radar' },
  zIndex: 108
})

// ② 数据进来后：设置颜色分段 + 格点数据 + 刷新
fillRangeColorSource.segements = toRaw(style)   // 颜色分段（min/max 动态生成）
fillRangeColorSource.datasetGrid = data          // 格点数据
fillRangeColorSource.refresh()                   // 触发重绘
```

**颜色分段数据结构：**

```js
type ColorValueSegment = {
  start: number, end: number,
  startColor: { red, green, blue },
  endColor?: { red, green, blue }
}
// 例如气温：[-10, 0, 蓝→绿], [0, 15, 绿→黄], [15, 40, 黄→红]
```

## 四、底层逻辑完整链路（面试重点）

```
后端返回格点数据
  ↓
dvalues 一维数组 + rows/cols + left/top/right/bottom + noDataValue
  ↓
封装成 DatasetGrid（提供经纬度↔行列换算、极值计算）
  ↓
根据 dMin/dMax 动态生成颜色分段 segements（值区间 → 渐变色）
  ↓
赋值给 FillRangeColorSource（继承 ImageCanvasSource）
  ↓
OpenLayers 视图变化 → 回调 canvasFunction
  ↓
内部：遍历格点 → convertValueToColor 值转色 → 写 ImageData 像素
  ↓
平滑/等值面插值交给 wcontour-js（isobands/isoline）
  ↓
整张 Canvas 作为一张图片贴到地图上
```

**关键点：**
1. **零 Feature 对象**：`FillRangeColorSource` 是 `ImageCanvasSource`，不创建任何 `ol/Feature`，没有事件系统、样式计算、逐对象遍历的开销
2. **逐像素渲染**：直接操作 `ImageData` 的 RGBA 数组，配合颜色查找表（LUT），性能极高
3. **平滑靠插值算法**：`isSmooth` 时用 `wcontour-js` 做等值面插值，`isGradient` 时颜色在分段间线性渐变
4. **规则网格假设**：`deltaX = width / cols`，所以只适合气象这种规则经纬度格点，不适合任意散点

## 五、面试话术

**当面试官问「你们格点图底层是怎么渲染的」：**

> "我们格点色斑图用的是 OpenLayers 的 **ImageCanvas 方案**，没有用 VectorLayer 逐点绑 Feature。具体是封装了一个继承 `ol/source/ImageCanvas` 的 `FillRangeColorSource`。
>
> 数据层用 `DatasetGrid` 把后端返回的规则网格数据封装起来——一维数组存值，加经纬度边界和行列数，内部提供经纬度跟行列号的互转，以及极值计算。
>
> 渲染层重写了 `canvasFunction`，OpenLayers 每次视图变化就回调一次。回调里遍历每个格点，通过 `convertValueToColor` 把格点值按颜色分段线性插值成 RGBA，直接写进 Canvas 的 `ImageData` 像素数组，整张 Canvas 作为一个图片贴到地图上。因为完全不创建 Feature 对象，没有事件系统和逐对象样式计算，上万个格点也很流畅。
>
> 平滑和等值面插值我们调的是气象领域经典的 `wcontour-js` 算法库，大量重复计算还用了 `gpu.js` 做 GPU 并行。风场则是单独的 `ol-wind` 图层做粒子动画。"

**当面试官追问「为什么不直接用 VectorLayer」：**

> "VectorLayer 每个格点都是一个 Feature 对象实例，带事件监听、属性系统、样式计算，渲染时每帧 O(n) 遍历所有 Feature。几万个格点内存和帧率都扛不住。ImageCanvas 方案本质是零对象、逐像素，性能差一到两个数量级，而且颜色映射和插值逻辑完全自定义。"

**当面试官追问「格点间距怎么算的」：**

> "我们假设是规则网格，`deltaX = (right - left) / cols`。这要求后端返回的是等间距经纬度格点，气象格点数据天然满足这个条件。如果是任意散点，就需要先插值成规则网格，或者换成热力图方案。"

## 六、技术要点速记表

| 维度 | 内容 |
|---|---|
| 图层方案 | `ImageCanvasSource`（`FillRangeColorSource` 继承它） |
| 数据模型 | `DatasetGrid`（一维数组 + 边界 + 行列 + deltaX/deltaY） |
| 索引方式 | 行优先：`(y * cols + x) * dimensions + dim` |
| 值→颜色 | `convertValueToColor` + 颜色分段线性插值 |
| 像素写入 | Canvas `ImageData`（RGBA 数组） |
| 平滑插值 | `wcontour-js`（`isobands` 等值面 / `isolines` 等值线） |
| GPU 加速 | `gpu.js` |
| 风场 | `ol-wind` 粒子动画 |
| 无数据 | `noDataValue`（-9999/-99999）跳过不渲染 |
