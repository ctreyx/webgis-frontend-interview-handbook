瓦片缓存架构:

TileSource
└── TileCache (LRU Cache)
├── maxSize: 默认 2048（可通过 cacheSize 配置）
├── 存储结构: key → Tile 的双向链表 + HashMap
│
│ ┌──────────────────────────────────┐
│ │ HashMap: O(1) 查找 │
│ │ "5/27/13" → Tile_A │
│ │ "5/28/13" → Tile_B │
│ │ "5/27/14" → Tile_C │
│ └──────────────────────────────────┘
│
│ ┌──────────────────────────────────┐
│ │ 双向链表: 维护访问顺序 │
│ │ HEAD(最近) ←→ ... ←→ TAIL(最久)│
│ │ Tile_B ←→ Tile_A ←→ Tile_C │
│ └──────────────────────────────────┘
│
├── get(key): 查找并移到链表头部
├── set(key): 插入头部，超出 maxSize 则淘汰尾部
└── pruneExceptNewestZ(): 清除非当前缩放级别的旧瓦片

缓存策略细节：

场景 行为
平移地图 新瓦片入缓存，旧瓦片保留直到缓存满
缩放地图 当前级别瓦片未加载完时，用上一级别瓦片拉伸显示（interim tile）
缓存溢出 LRU 淘汰最久未使用的瓦片
来回平移 已缓存的瓦片直接复用，无需重新请求
