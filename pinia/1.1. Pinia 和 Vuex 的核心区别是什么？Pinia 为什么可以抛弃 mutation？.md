# 1. Pinia 和 Vuex 的核心区别是什么？Pinia 为什么可以抛弃 mutation？

Vuex 为什么需要 mutation：
Vuex 用 mutation 的原因是为了让状态变更可追踪
严格模式下只有 mutation 能改 state
action → commit(mutation) → 改 state
→ 流程繁琐，异步必须在 action 里，同步必须在 mutation 里

Pinia 为什么能抛弃 mutation：

1. Vue3 的响应式系统本身就能追踪变更（devtools 支持）
   不需要强制走 mutation 来追踪
2. action 直接支持同步和异步，不需要区分
3. 直接修改 state 也可以被 devtools 追踪
4. 代码量减少 50%，更符合直觉
