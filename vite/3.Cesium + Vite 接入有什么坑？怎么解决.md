# Cesium + Vite 接入有什么坑？怎么解决？

# 坑② CESIUM_BASE_URL 全局变量未定义

1
你需要确保设置全局变量 `window.CESIUM_BASE_URL`，这样 CesiumJS 代码才能访问到它需要的文件。
JavaScript

// vite.config.js
export default defineConfig({
define: {
CESIUM_BASE_URL: JSON.stringify(cesiumBaseUrl),
},
});

# 坑⑤ Cesium 体积巨大，打包慢 + 产物大

JavaScript

// 手动分包，避免主 chunk 过大
build: {
rollupOptions: {
output: {
manualChunks(id) {
if (id.includes('node_modules/cesium')) {
return 'cesium'; // 独立成一个 chunk
}
},
},
},
},
