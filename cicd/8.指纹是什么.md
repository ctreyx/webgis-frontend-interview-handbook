# 我想问一个很直接的问题：什么是内容指纹？你具体怎么实现的？为什么不用行号？


以下情况：
 "文件开头加了 import 导致行号变了，但指纹没变所以不受影响"。用 Node.js 的 crypto 模块做 sha1 哈希，先将代码清洗空格等，然后crypto做哈希。


 指纹变了说明这行代码被改过了。既然改过了，之前的忽略理由可能已经不成立了，所以豁免自动失效，逼你重新审视这行代码要不要继续忽略。这就保证了忽略文件不会变成'一劳永逸的免检通道'。



 function fingerprint(codeField) {
  return crypto.createHash('sha1').update(codeField).digest('hex').slice(0, 12)
}
