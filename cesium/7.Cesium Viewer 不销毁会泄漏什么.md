# Cesium Viewer 不销毁会泄漏什么 
┌──────────────────────────────────────────────────────┐
│  Cesium Viewer 内部持有大量资源：                      │
│                                                       │
│  1. WebGL 上下文（Context）                            │
│     每个 Viewer 对应一个 WebGL context                 │
│     浏览器对 WebGL context 数量有限制                  │
│     Chrome 最多同时存在 16 个                          │
│     不销毁 → context 耗尽 → 新的 Viewer 创建失败       │
│                                                       │
│  2. GPU 显存                                          │
│     地形、影像、模型都上传到 GPU 显存                    │
│     不销毁 → 显存一直占用 → 页面越来越卡                │
│                                                       │
│  3. 内部定时器和 requestAnimationFrame                 │
│     Cesium 内部有渲染循环                               │
│     每帧都在执行                                       │
│     不销毁 → 组件卸载了渲染循环还在跑                   │
│     → CPU 持续消耗                                     │
│                                                       │
│  4. 事件监听                                           │
│     鼠标事件、键盘事件、resize 事件                     │
│     不销毁 → 事件监听一直存在                           │
│     → 可能触发已销毁组件的逻辑                          │
└──────────────────────────────────────────────────────┘
