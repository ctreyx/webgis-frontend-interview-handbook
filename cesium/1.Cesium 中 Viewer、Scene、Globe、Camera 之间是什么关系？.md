# Cesium 中 Viewer、Scene、Globe、Camera 之间是什么关系？

Viewer（最顶层容器，"万能遥控器"）
├── Scene（三维场景，核心渲染引擎）
│ ├── Globe（地球椭球体 + 地形 + 影像图层）
│ │ ├── EllipsoidTerrainProvider / CesiumTerrainProvider
│ │ └── ImageryLayerCollection
│ ├── Camera（相机/视角控制）
│ │ ├── position, direction, up, right
│ │ └── flyTo(), lookAt(), setView()...
│ ├── SkyBox / SkyAtmosphere / Sun / Moon
│ ├── Primitives（底层图元集合）
│ └── ScreenSpaceCameraController
├── DataSourceCollection（Entity 数据源）
├── Clock / Timeline / Animation
├── SelectionIndicator / InfoBox
└── 各种 Widget（BaseLayerPicker, Geocoder...）

```js
const viewer = new Cesium.Viewer("cesiumContainer");

// Viewer 是"糖衣"——它把 Scene 和各种 Widget 黏合在一起
// Scene 是真正的"三维世界"
const scene = viewer.scene;

// Globe 是 Scene 里的"地球"
const globe = scene.globe;
globe.show = false; // 隐藏地球，只剩太空

// Camera 是 Scene 里的"眼睛"
const camera = scene.camera;
camera.flyTo({
  destination: Cesium.Cartesian3.fromDegrees(116.4, 39.9, 15000000),
});
```

一句话总结：Viewer 是全家桶，Scene 是渲染引擎，Globe 是地球本身，Camera 是我们的眼睛。
