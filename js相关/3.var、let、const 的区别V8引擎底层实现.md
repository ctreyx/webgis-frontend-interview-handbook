# 执行上下文的两个环境

┌──────────────────────────────────────────────────────┐
│  执行上下文（Execution Context）                       │
│                                                       │
│  ┌─────────────────────────────────────────────┐     │
│  │  变量环境（Variable Environment）             │     │
│  │                                             │     │
│  │  专门存 var 声明的变量                        │     │
│  │  创建时立即初始化为 undefined                 │     │
│  │  这就是为什么 var 有变量提升                  │     │
│  └─────────────────────────────────────────────┘     │
│                                                       │
│  ┌─────────────────────────────────────────────┐     │
│  │  词法环境（Lexical Environment）              │     │
│  │                                             │     │
│  │  专门存 let / const 声明的变量               │     │
│  │  创建时不初始化，状态是 uninitialized         │     │
│  │  访问 uninitialized 的变量就报 ReferenceError │     │
│  │  这就是暂时性死区的本质                       │     │
│  └─────────────────────────────────────────────┘     │
└──────────────────────────────────────────────────────┘


# 块级作用域怎么实现的

┌──────────────────────────────────────────────────────┐
│  V8 遇到 {} 块的时候：                                 │
│                                                       │
│  {                                                    │
│    let a = 1    ← 进入块，创建新的词法环境              │
│    const b = 2  ← a、b 存在这个新的词法环境里           │
│  }              ← 离开块，这个词法环境销毁              │
│                                                       │
│  外部无法访问 a、b                                     │
│  因为它们所在的词法环境已经不存在了                      │
└──────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────┐
│  但 var 不一样：                                       │
│                                                       │
│  {                                                    │
│    var c = 3   ← var 不存在词法环境里                   │
│  }             ← 直接存在函数/全局的变量环境里            │
│                                                       │
│  块销毁了，变量环境还在                                 │
│  所以 c 在块外还能访问                                  │
└──────────────────────────────────────────────────────┘



全局执行上下文
│
├── 变量环境
│     var a = undefined（提升，初始化为 undefined）
│
├── 词法环境（全局层）
│     let b = uninitialized（提升，但未初始化）
│
│   进入 {} 块
│   └── 词法环境（块级）
│         let c = uninitialized
│         const d = uninitialized
│         （块结束后这层词法环境销毁）


# 总结
var 存在变量环境，提升后初始化为 undefined。let/const 存在词法环境，提升后状态是 uninitialized，访问就报错，这是 TDZ 的本质。块级作用域是通过每个 {} 创建独立的词法环境实现的，块结束词法环境销毁，外部自然访问不到
