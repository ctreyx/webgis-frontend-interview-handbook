# async/await 本质上是什么


# 总结
Generator 的 yield 不是真正停止执行，而是把当前执行上下文从调用栈弹出但不销毁，挂起保存在 Generator 对象里。调用 next() 时再把它压回调用栈继续执行。async/await 就是 Generator + 自动执行器的语法糖，让你不用手动调 next()。


普通函数 vs Generator 函数的本质区别


┌──────────────────────────────────────────────────────┐
│  普通函数：                                            │
│                                                       │
│  调用 foo()                                           │
│    ↓                                                  │
│  创建执行上下文，压入调用栈                              │
│    ↓                                                  │
│  函数执行完毕                                          │
│    ↓                                                  │
│  执行上下文从调用栈弹出，销毁                            │
│  局部变量全部释放                                       │
└──────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────┐
│  Generator 函数：                                      │
│                                                       │
│  调用 gen()                                           │
│    ↓                                                  │
│  不会立即执行！                                         │
│  只是创建了一个 Generator 对象，返回给你                │
│    ↓                                                  │
│  调用 gen.next()                                      │
│    ↓                                                  │
│  创建执行上下文，压入调用栈，开始执行                    │
│    ↓                                                  │
│  遇到 yield                                           │
│    ↓                                                  │
│  执行上下文从调用栈弹出                                 │
│  但是！！不销毁！！                                     │
│  保存在 Generator 对象内部                              │
│    ↓                                                  │
│  再次调用 gen.next()                                   │
│    ↓                                                  │
│  把之前保存的执行上下文重新压回调用栈                    │
│  从上次 yield 的位置继续执行                            │
└──────────────────────────────────────────────────────┘


# 关键点：执行上下文被"挂起"而不是销毁
正常函数调用栈：

┌──────────┐
│  foo()   │  ← 执行完弹出，销毁
├──────────┤
│  main()  │
└──────────┘


Generator yield 时：

调用栈                Generator 对象内部
┌──────────┐         ┌─────────────────────┐
│  main()  │         │  挂起的执行上下文     │
└──────────┘         │  - 局部变量          │
                     │  - 当前执行位置       │
                     │  - 作用域链           │
                     └─────────────────────┘

next() 时：
┌──────────┐
│  gen()   │  ← 把挂起的上下文重新压回来
├──────────┤
│  main()  │
└──────────┘
