# 第一个：WeakMap 为什么不会内存泄漏

┌──────────────────────────────────────────────────────┐
│  Map 的问题：强引用                                    │
│                                                       │
│  let obj = { name: 'cesium' }                        │
│  const map = new Map()                                │
│  map.set(obj, 'viewer')                               │
│                                                       │
│  obj = null   ← 你以为对象被回收了                     │
│                                                       │
│  但是！map 内部还持有 obj 的强引用                      │
│  GC 看到 map 还引用着这个对象                           │
│  不敢回收！                                            │
│  obj 对应的内存永远不会被释放                           │
│  这就是内存泄漏                                        │
└──────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────┐
│  WeakMap 的解决：弱引用                                │
│                                                       │
│  let obj = { name: 'cesium' }                        │
│  const weakmap = new WeakMap()                        │
│  weakmap.set(obj, 'viewer')                           │
│                                                       │
│  obj = null   ← 对象没有其他强引用了                   │
│                                                       │
│  WeakMap 持有的是弱引用                                │
│  GC 不把弱引用算作"被引用"                              │
│  发现没有强引用了 → 直接回收这个对象                    │
│  WeakMap 里对应的条目自动消失                           │
└──────────────────────────────────────────────────────┘


│  强引用 vs 弱引用：                                    │
│                                                       │
│  强引用：GC 不敢回收，"我还在用这个对象"               │
│  弱引用：GC 可以回收，"我不阻止你回收这个对象"          │
│                                                       │
│  WeakMap 的 key 只能是对象                             │
│  就是因为弱引用只对对象有意义                           │
│  基本类型没有引用的概念
