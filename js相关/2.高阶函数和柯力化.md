# 高阶函数

满足以下任意条件：

1. 接受一个函数作为参数
2. 返回一个函数

## 示例 1：接收函数作为参数

```js
[1, 2, 3]
  .map((x) => x * 2) // map 是高阶函数
  [(1, 2, 3)].filter((x) => x > 1) // filter 是高阶函数
  [(1, 2, 3)].reduce((acc, x) => acc + x, 0); // reduce 是高阶函数
```

## 示例 2：返回一个函数

```js
function multiply(x) {
  return function (y) {
    // ← 返回函数
    return x * y;
  };
}

const double = multiply(2);
double(5); // 10
```

高阶函数是函数缺失和延续，比如 map 里面需要一个计算函数，所以我们传入函数进去；bind 返回一个函数，方便我们后续使用，就是延续。

# 柯里化

把一个接收多个参数的函数，转化成一系列每次只接收一个参数的函数。

## 普通函数：一次传所有参数

```js
function add(a, b, c) {
  return a + b + c;
}

add(1, 2, 3); // 6
```

## 柯里化后：每次传一个参数

```js
function curriedAdd(a) {
  return function (b) {
    return function (c) {
      return a + b + c;
    };
  };
}

curriedAdd(1)(2)(3); // 6
```

## 可以提前固定部分参数

```js
const add1 = curriedAdd(1); // 固定了 a = 1
const add1and2 = add1(2); // 固定了 b = 2

add1and2(3); // 6
add1and2(10); // 13
```
